# ¿Dónde lo encuentro? — Comercia (Demo)

> **⚠️ Simulación:** Todos los datos (productos, precios, negocios) son ficticios. Es una demo, no un servicio real.

Demo de directorio local para Sancti Spíritus, Cuba: busca un producto o servicio y ve en qué negocio está, a qué precio y quién lo vende.

🔗 **Demo:** https://edisbelramirezdev.github.io/demo/index.html

## Características
- Búsquedas populares con tendencia (↑↓) y ofertas
- Filtros: abierto ahora, cerca de mí, disponible hoy, con entrega, mejor valorados
- 20 categorías y 37 productos/servicios de ejemplo
- Negocios tipo **TCP** (cuenta propia) y **Mipyme**

## Tech
Sitio estático (HTML/CSS/JS) en GitHub Pages. Sin backend ni datos reales.
